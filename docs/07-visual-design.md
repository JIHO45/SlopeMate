# 07. 화면 디자인 기준

작성: 2026-11-08 · 깊이: 가볍게 · 상태: 검토 대기

Claude Design에 넘길 디자인 기준이다. 토큰과 컴포넌트는 [SlopeMate 디자인 시스템](https://claude.ai/artifact/Lgke1C5Hx6s2BWHuiS3Uyg)에 있다. 화면의 목적과 상태는 [04-flows](04-flows.md), 색 결정의 이유는 [decisions](decisions.md) 2026-11-08 항목을 따른다. 시안은 HTML 참고용이고 구현은 SwiftUI 기본 구성요소로 한다.

## 1. 쓰는 환경

| 환경 | 디자인 기준 |
| --- | --- |
| 장갑 낀 손 | 주요 버튼 높이 60pt 이상. 기록 시작·종료는 화면 폭 버튼. 작은 아이콘 버튼은 핵심 동작에 쓰지 않는다 |
| 밝은 설원, 눈부심 | 본문 대비 4.5 이상, 큰 숫자·버튼 글씨 3 이상. 얇은 서체와 옅은 회색 글씨를 쓰지 않는다 |
| 리프트에서 몇 초 보기 | 기록 중 화면(S5)은 기본 글씨에서 스크롤 없이 한 화면. 숫자 3개(경과 시간, 하강 횟수, 거리)가 가장 크다 |
| 추위, 한 손 | 주요 동작은 화면 아래 절반에 둔다 |
| 야간 스키, 잠금 화면 | 다크 모드를 같은 무게로 디자인한다. Live Activity는 어두운 배경 기준 |
| 큰 글씨, VoiceOver (R21) | 최대 글씨에서 스크롤을 허용하되 기록 시작·종료, 계정 삭제를 끝까지 할 수 있어야 한다. 색만으로 상태를 구분하지 않는다(아이콘과 문구 함께) |

## 2. 색 (60·30·10)

| 역할 | 밝게 | 어둡게 |
| --- | --- | --- |
| 60 바탕 | `#F6FAFB` | `#0B161B` |
| 30 카드·보조 면 | 얼음색 `#DDEFF2` | `#14303A` |
| 10 강조 면(버튼, 막대) | 딥 틸 `#0E9AA7`, 글씨 검정 | 프로스트 `#5CE1E6`, 글씨 바탕색 |
| 10 강조 글씨·숫자 | `#087480` | 프로스트 `#5CE1E6` |
| 보조 글씨 | `#4A636C` | `#86A0A8` |

- **배경 그라데이션:** 기록 홈과 기록 중 화면은 맨 위에서 하늘색으로 시작해 아래로 서서히 바탕색이 된다. 밝게는 `#CDEAF0`(기록 중 `#B9E6EC`)에서 `#F6FAFB`로, 어둡게는 `#153A43`(기록 중 `#123139`)에서 `#0B161B`로. 카드와 큰 숫자가 놓이는 곳에서는 거의 바탕색이어야 한다. 색 면을 수평으로 잘라 화면을 나누지 않는다. 이 그라데이션 말고는 쓰지 않는다.
- **강조색을 쓰는 곳:** 화면마다 주요 버튼 하나, 핵심 숫자, 현재 상태 아이콘, Live Activity의 하강 횟수. 나머지는 바탕·카드·글씨 색으로 둔다.
- **상태 색:** 경고(신호 약함, 배터리, 저장 공간)는 중립 카드에 노란 아이콘. 멈춤·저장 실패·권한 꺼짐은 빨간 배너에 아이콘. 자동 재개 안내는 중립 카드에 강조색 아이콘.
- **슬로프 난이도:** 초급 `#2E9E4F`, 중급 `#3A4FB8`, 상급 `#D93A3A`. 데이터에 있을 때만 점으로 보여준다(R9).
- **예상 설질:** "예상" 표시를 테두리만 있는 작은 태그로 붙여, 사용자가 남긴 설질(채운 태그)과 모양으로 구분한다(R39, R11).

## 3. 글씨

- 시스템 서체(SF Pro, Apple SD 산돌고딕 Neo). Dynamic Type 크기 단계를 그대로 쓴다.
- 숫자는 고정폭 숫자로 써서 시간이 바뀔 때 흔들리지 않게 한다.
- 굵기는 보통과 굵게 두 단계. 큰 숫자만 더 굵게 쓴다.

## 4. 공통 요소

| 요소 | 쓰는 곳 |
| --- | --- |
| 큰 버튼 (화면 폭, 60pt) | 기록 시작, 종료(길게 누르기 또는 확인 창, 시안 단계에서 정함) |
| 요약 카드 (30 면, 큰 숫자 + 짧은 설명) | S2 시즌 요약·날씨, S6 합계, S9 합계·시즌권 |
| 상태 배너 5종 | 신호 약함, 권한 꺼짐, 배터리, 저장 실패, 자동 재개 |
| 하강 행 (시각, 난이도 점, 이름, 거리) | S6, S8 |
| 기록 없음 행 (점선 점, 회색 글씨) | S6 |
| 막대 | S9 리조트별 방문일 |

아이콘은 SF Symbols를 쓴다. 탭 이름과 아이콘은 시안 단계에서 정한다(04-flows 5장).

## 5. 레퍼런스 (문제별)

특정 앱의 화면을 그대로 옮기지 않고, 문제마다 해법만 참고한다.

| 문제 | 참고 | 볼 점 |
| --- | --- | --- |
| 기록 중 큰 숫자 (S5, Live Activity) | Apple 운동 앱의 운동 중 화면, 피트니스 Live Activity | 숫자 위계, 잠금 화면에서 읽히는 크기 |
| 하루·시즌 요약 (S6, S9) | Apple 피트니스 요약, 건강 앱 카드 | 카드 하나에 숫자 하나, 기간 바꾸기 |
| 날씨·예상 설질 (R33, R39) | Apple 날씨 | 시간대별·7일 배치, 출처 표시 위치 |
| 분위기 | 맑은 날 설원과 하늘, 야간 스키장 조명 사진 | 밝은 화면은 눈과 하늘, 어두운 화면은 야간 슬로프 |

Claude Design에 넣을 때는 이 표와 2장 색 값을 글로 주고, 가진 스크린샷이나 현장 사진이 있으면 함께 올린다.

## 6. 핵심 시안 5개 (11월 10일 동결)

**확정 (2026-11-08):** [캔버스](https://claude.ai/artifact/QgzyasT1JLPb9HpLB8rmhj)의 아래 판으로 구현한다.

| 화면 | 확정 판 | 요점 |
| --- | --- | --- |
| S2 기록 홈 | v10 카드 높이 줄임 (배경은 v9) | 위 하늘색에서 바탕색으로 사라지는 배경, 이번 시즌 방문일 큰 숫자 + 횟수·거리 한 줄, 옆으로 넘기는 큰 카드(날씨 → 최근 기록 → 시즌권; 높이 200, 본문은 아이콘 바로 아래, 출처 줄은 카드 맨 아래), 리조트를 보여주는 기록 시작 카드, 유리 탭 막대 |
| S5 기록 중 | v7 | 그라데이션 배경, 위에서부터 경과 시간·하강(가장 큼)·거리, 마지막 위치는 리조트 이름 아래, 하단은 강조색 "길게 눌러 종료" 버튼 하나, 설질 칸 없음 |
| S6 하루 기록 | v3 | 전체 화면 지도(리조트 전체 슬로프 + 오늘 경로), 위 유리 버튼(뒤로·공유), 아래 유리 시트 25%(재생 막대·합계)·50%(+세션별 하강 목록), 탭 막대 숨김 |
| S9 시즌 기록 | v1 | 시즌 고르기, 방문일 큰 숫자 + 횟수·거리, 시즌권 카드, 리조트별 막대 |
| Live Activity | v2 숫자 라벨 있음 | 윗줄 "하이원 | 기록 중", 숫자 줄 경과·하강·거리와 라벨, 멈춤·8시간 상태 |

빈 상태와 오류 상태(날씨 조회 실패, 배너 5종, 하강 0회 등)는 화면을 구현할 때 04-flows의 문구와 디자인 시스템 컴포넌트로 그리고, 그린 화면을 같은 캔버스에 추가한다. 아래는 처음 계획한 시안별 내용이다.

1. **S2 기록 홈:** 날씨·예상 설질 요약(불러오는 중, 조회 실패 포함), 시즌 요약, 시즌권 카드(있을 때만), 저장 공간 경고, 기록 시작
2. **S5 기록 중:** 숫자 3개, 현재 상태, 마지막 위치 수신, 그 아래 설질 칸(이름 표시 켬·끔 두 가지), 배너 5종, 종료
3. **S6 하루 기록:** 합계, 세션별 묶음, 하강 행, 기록 없음 행, "고도 정확도 낮음", 하강 0회 빈 상태
4. **S9 시즌 기록:** 합계, 리조트별 막대, 시즌권 카드(1장, 2장 이상 합계), 방문일 0일 빈 상태
5. **Live Activity:** 잠금 화면과 다이나믹 아일랜드(간단·확장), 상태 5단계(기록 중, 멈춤, 8시간 뒤, 앱을 열면 새로 시작, 종료)

나머지 화면은 시안 없이 이 기준과 SwiftUI 기본 화면으로 만든다.

## 7. Liquid Glass (iOS 26 이상)

- 탭 막대, 상단 툴바 버튼, 시트는 SwiftUI 기본 요소로 만들어 iOS 26 이상에서 자동으로 유리 모양이 되게 한다. 그 위에 바탕색이나 구분선을 직접 칠하지 않는다.
- 기록 중일 때 홈의 탭 막대 위에 "기록 중 · 하이원 · 12회 · 2:14:08" 막대(`tabViewBottomAccessory`). 누르면 S5.
- 하루 기록(S6)은 전체 화면 지도 위에 기본 시트(`presentationDetents` 약 25%·50%, 뒤 지도 조작 가능)를 띄우고 탭 막대를 숨긴다. iOS 26에서 시트는 자동으로 유리가 되고, iOS 17.6~25는 `presentationBackground(.regularMaterial)`로 지도가 흐리게 비치게 한다. 지도는 시트 뒤까지 전체 화면을 유지하고 보이는 영역에 맞춰 중심만 옮긴다.
- 큰 버튼, 요약 카드, 기록 숫자, 상태 배너는 유리를 쓰지 않는다(눈부심 아래 대비).
- iOS 17.6~25는 같은 배치를 이 문서의 단색으로 그린다.

## 8. 하지 않는 것

- 위쪽 배경 그라데이션(2장) 말고 다른 그라데이션, 그림자 위주 장식, 얇은 서체
- 화면마다 다른 강조색
- 날씨 출처 표시(Apple Weather 마크, 법적 출처 링크) 생략
