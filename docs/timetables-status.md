## 앱에 입력한 것

### 알펜시아

- 주간 09:00~17:00 (오전권 09~13, 오후권 13~17을 주간 하나로)
- 야간 18:30~21:30, 2026-12-19~2027-02-13에만
- 정설 17:00~18:30
- 기간: 2026-11-28(임시)~2027-03-07
- 출처: https://www.alpensia.com/ski/use-cost-lift.do (2026~2027 날짜 표기)
- 남은 것: 시작일을 실제 개장일로

### 비발디파크

- 주간 09:00~17:30, 야간 19:00~23:00, 심야 23:00~03:00
- 심야 휴무: 월요일 23:00~화요일 03:00. 2027-02-08(월)만 정상 운영
- 정설 17:30~19:00 (블루스·힙합Ⅰ·힙합Ⅱ는 17:00~19:00), 락 슬로프는 09:00~17:00
- 기간: 2026-11-28(임시)~2027-03-01
- 출처: https://www.sonohotelsresorts.com/skiboard/info (공식 페이지에는 09:00~03:00과 정설만 있고, 주간·야간·심야 경계는 그것으로 읽은 값)
- 남은 것: 시작일을 실제 개장일로. 지난 시즌에는 심야가 12/19에 시작했으므로, 오픈 안내(11/27 전후 예상)와 심야 공지(12/10 전후 예상)를 보고 심야 시작일을 나눔
