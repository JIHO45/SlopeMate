# 개인정보처리방침

슬로프메이트(이하 "앱")는 이용자의 개인정보를 아래와 같이 처리합니다. 시행일: 앱 2.0 출시일

## 1. 기기에만 저장하고 보내지 않는 정보

GPS 위치, 이동 경로, 하강별 기록, 날짜별 기록, 동작 및 피트니스 정보(기압 고도, 차량 이동 여부)는 이용자의 기기에만 저장합니다. 앱 운영자의 서버나 분석·오류 수집 도구로 보내지 않습니다. 계정 없이도 기록 기능을 모두 쓸 수 있습니다.

다만 가입하지 않아도 앱은 인터넷으로 설정 파일(슬로프 이름 표시, 운영 시간표)과 리조트 날씨를 받습니다. 이때 접속 IP 주소는 해당 서버(Google, Apple)에서 처리됩니다. GPS 위치와 경로는 이 요청에 들어가지 않습니다. 슬로프 지도와 지형은 앱에 들어 있어 지도를 볼 때는 통신하지 않습니다.

## 2. 처리하는 개인정보와 목적

| 구분 | 항목 | 목적 |
| --- | --- | --- |
| 크루 가입(선택) | Apple 로그인으로 받은 계정 식별자, 표시 이름, 만 14세 이상 확인 여부 | 크루 기능 제공, 본인 확인, 연령 확인 |
| 크루 이용 | 크루 소속, 이번 시즌 합계(방문일·하강 횟수·거리), 리조트별 방문일 수 | 크루원 간 순위 표시 |
| 신고 | 신고한 계정, 신고 대상(크루·계정), 신고 당시 이름 | 부적절한 이름 확인과 조치, 결과 안내 |
| 설질·대기 시간 익명 전송(선택, 동의) | 리조트, 슬로프 또는 리프트, 날짜와 15분 단위 시간대, 직접 남긴 설질 평가 또는 리프트 대기 시간. 계정·기기 식별자·정확한 시각·위치 좌표는 보내지 않습니다. | 리조트별 설질·대기 현황 통계. 받는 즉시 시간대별 개수만 더하고 보낸 내용은 저장하지 않습니다. |
| 문의 | 이메일 주소, 문의 내용 | 문의 답변 |
| 서비스 이용 중 자동 생성(가입 여부와 무관) | 서버 접속 기록(IP 주소, 접속 시각, 요청 정보): 설정 파일·날씨 조회, 초대 웹페이지 방문, 크루 기능 사용 | 서비스 제공, 오류 확인, 부정 이용 방지 |

Apple 로그인에서 이름과 이메일은 받지 않습니다. 표시 이름은 이용자가 직접 입력합니다.

시즌 이용권 결제는 Apple이 처리합니다. 앱 운영자는 카드 번호 등 결제 수단 정보를 받지 않습니다. 이용권이 있는지는 기기에서 Apple 구입 내역으로 확인하며 운영자 서버로 보내지 않습니다.

## 3. 익명 설질·대기 시간 정보(동의한 경우)

설정에서 "설질·대기 시간 익명으로 보내기"를 켠 경우에만 리조트, 슬로프·리프트, 날짜와 15분 단위 시간대, 설질 또는 리프트 대기 시간을 보냅니다. 계정, 기기 식별자, 정확한 시각, 좌표는 넣지 않습니다. 서버는 받은 즉시 시간대별 집계 숫자만 남기고 보낸 정보 하나하나는 저장하지 않습니다. 언제든 설정에서 끌 수 있고, 끄면 아직 보내지 않은 정보는 버립니다.

## 4. 크루원과 초대받은 사람에게 보이는 정보

같은 크루원에게는 표시 이름, 이번 시즌 합계, 리조트별 방문일 수가 보입니다. 초대 링크를 받은 사람은 가입 전에도 크루 이름, 인원, 크루장 표시 이름을 볼 수 있습니다. 경로와 위치는 보이지 않습니다.

이용자의 개인정보를 제3자에게 제공하지 않습니다. 법령에 따라 요구되는 경우는 예외입니다.

## 7. 처리 위탁과 국외 이전

| 받는 자 | 내용 | 장소 |
| --- | --- | --- |
| Google LLC (Firebase: Cloud Firestore, Cloud Functions) | 계정, 크루, 시즌 합계, 신고 저장과 처리 | 대한민국(서울 리전) |
| Google LLC (Firebase Authentication) | 로그인 처리: 계정 식별자, 로그인 기록(IP 주소) | 미국 |

| Google LLC (Firebase App Check), Apple Inc. (App Attest) | 익명 전송과 크루 기능 요청이 정품 앱에서 왔는지 확인(기기 증명, 계정과 연결하지 않음) | 미국 등 |
| Apple Inc. (Sign in with Apple, WeatherKit) | 로그인(가입한 경우), 리조트 위치의 날씨 조회(가입 여부와 무관, 이용자 위치는 보내지 않음) | 미국 등 |

국외 이전은 이용자가 크루 가입·로그인·서비스 이용을 할 때 네트워크로 전송되며, 보유 기간은 5항과 같습니다. 크루에 가입하지 않으면 계정 정보는 이전되지 않지만, 설정 파일과 날씨 조회의 접속 IP 주소는 가입 여부와 관계없이 위 서버에서 처리됩니다.

계정 정보의 국외 이전을 원하지 않으면 크루에 가입하지 않거나 앱에서 계정을 삭제하면 됩니다. 이 경우 크루 기능을 쓸 수 없고, 기록 기능은 그대로 쓸 수 있습니다. 설정 파일과 날씨 조회는 인터넷에 연결된 동안 자동으로 이루어지며, 연결이 없어도 기록 기능은 동작합니다.

받는 자의 개인정보 처리: [Google 개인정보처리방침](https://policies.google.com/privacy?hl=ko), [Apple 개인정보 처리방침](https://www.apple.com/kr/legal/privacy/)

## 8. 이용자의 권리

이용자는 앱에서 표시 이름 변경(다시 로그인할 때), 크루 나가기, 계정 삭제, 익명 전송 끄기를 할 수 있습니다. 열람·정정·삭제·처리 정지 요청은 아래 연락처로 보내 주시면 지체 없이 처리합니다.

## 9. 만 14세 미만

크루 가입은 만 14세 이상만 할 수 있습니다. 만 14세 미만은 계정 없이 기록 기능만 쓸 수 있으며, 이 경우 계정·표시 이름·시즌 합계를 받지 않습니다. 설정 파일과 날씨 조회의 접속 IP 주소는 1항과 같이 처리됩니다.

## 10. 안전성 확보 조치

모든 전송은 암호화(HTTPS)합니다. 서버 데이터는 보안 규칙으로 본인과 같은 크루원만 읽을 수 있게 제한하고, 변경은 서버 함수만 합니다.

## 11. 쿠키와 광고 식별자

앱은 쿠키, 광고 식별자, 분석·광고 도구를 쓰지 않습니다.

## 기록은 어디에 저장되나요?

위치와 이동 경로는 이 기기에만 저장돼요. 서버로 보내지 않아요. 앱을 지우면 기록도 사라져요.

## 크루에서 나가려면

크루 탭에서 크루를 열고 오른쪽 위 설정 → 크루 나가기를 눌러요. 크루장이 나가면 다음에 가입한 사람이 크루장이 돼요.

## 계정을 지우려면

기록 탭 오른쪽 위 설정 → 계정 → 계정 삭제를 눌러요. 계정, 이번 시즌 활동 합계, 크루 소속, Apple 로그인 연결이 지워져요. 기기의 기록은 남아요.

## 부적절한 이름을 신고하거나 차단하려면

크루 설정 → 크루 이름·표시 이름 신고에서 신고해요. 크루 순위에서 크루원 옆 … 버튼을 누르면 그 사람을 신고하거나 차단할 수 있어요. 차단한 사람은 모든 크루 순위에서 보이지 않아요. 신고는 확인한 뒤 48시간 안에 조치하는 것을 목표로 해요.
