# SlopeMate 킥오프 상태

마지막 업데이트: 2026-11-08 · **킥오프 완료**

## 아이디어 요약

- **무엇:** 국내 스키장에서 탄 슬로프, 횟수, 거리를 자동으로 기록하고 시즌 누적 기록과 비교·랭킹을 보여주는 iOS 앱. 날씨와 운영 정보는 보조 기능
- **누구:** 스키장에 가는 모든 사람. 1순위는 시즌권자·자주 가는 사람
- **범위:** 국내 스키장 전용. 국내 스키 환경에 특화한 기능으로 차별화. iPhone 먼저, 반응이 좋으면 안드로이드, 그다음 해외(장기 목표)
- **만드는 사람:** 1인 개발, 주 40시간. 현장 검증은 TestFlight 테스터
- **출시 목표:** 이번 시즌(2026-27)은 TestFlight로 단계 배포하며 현장 데이터 수집, 3월 초 개발 완료. 앱스토어 출시는 다음 시즌 개장(2027년 11월). 모든 국내 리조트에서 기록, 슬로프 이름은 현장 테스트 통과 리조트부터. 테스터는 개발 이후에 정함(TBD). 개인 기록, D1·D2, D5 크루 기록. D3·D4는 데이터만 수집
- **데이터 구조:** 홈 리조트는 사용자가 직접 선택(여러 개 가능). GPS는 기기 안에서만. 서버에는 횟수·거리·날짜·선택한 리조트만

## 기능 후보 (03-requirements에서 분류 예정)

- 핵심: 자동 트래킹, 기록 보존, 국내 슬로프 인식(OSM 기반), 하루·시즌 기록, 개인 목표 → 친구·크루 비교 → 공개 랭킹
- 기본 기록 목표: 국내 스키장 기준 Slopes 수준
- 차별점: D2 주간·야간·심야 세션 기록, D3 슬로프별 시간대 설질, D4 리프트 대기 시간
- 국내 기본기: D1 시즌권 본전 계산, D5 크루 기록 (사용자가 모이면 크루 간 경쟁·보상)
- TBD: D6 강습 기록 공유, 보상 형태
- 나중: 사용자 주행 감지 구간, 설질 점수(D3 데이터 기반)
- 보조: 날씨, 운영 시간, 공식 링크, 강풍 경고
- 제외: 파우더 알림, 영어 지원, iPad 레이아웃, 최고 속도 랭킹
- 검토 대상: 시간대별 날씨, 즐겨찾기, 위젯, Apple Watch, 관심 슬로프 알림, 고도별 기온, 가는 길 정보

## 열린 가정과 질문

- 가장 위험한 가정: 시즌권자가 이 앱으로 기록하고 다시 쓴다 (01-idea B1). 코드 전에 시안으로 검증
- 위치정보법: 직접 선택 + 기기 안 GPS 구조가 신고 대상이 아닌지 위치정보지원센터에 확인 (B4)
- 무료로 운영할지 정해지지 않음. 서버 비용 상한과 리조트 문의서 범위가 이 결정에 달려 있음
- 날씨 데이터 출처: WeatherKit 잠정, 여름에 기상청과 비교 (06-verification)
- 설질 점수 규칙이 실제 체감 설질과 맞는지 확인되지 않음
- 리조트들이 데이터 이용을 허락할지 확인되지 않음 (전체 일괄 문의 예정)

## 완료 (2026-11-08)

모든 문서가 승인됐다. 다음 단계는 개발이다.

**첫 개발 단계:** 기록 엔진(05-design A)부터. 위치·기압 고도를 받아 즉시 저장하고 파일로 내보내는 최소 앱을 먼저 만들어 TestFlight 테스터에게 배포한다. 이번 시즌 현장 데이터를 하루라도 빨리 모으는 것이 하강 판정(B)과 모든 기준값의 출발점이다.

**앱스토어 등록:** 기존 SlopeMate 등록을 업데이트로 이어 쓰고, 버전은 2.0부터 시작한다. 코드는 같은 저장소에서 05-design대로 새로 짠다.
